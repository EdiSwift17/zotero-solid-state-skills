# 固态电池文献遴选、归档与深读

## 输入与每次交付

每次只处理一篇。调用方指定以下一种模式；若未指定，依据用户当前请求判断，不自行批量运行。

- `classic`：固态电池领域高质量综述或有持续影响的经典论文；出版年份不限。优先兼顾固态电解质、界面与电池设计，不把单纯高引用量当作质量证明。
- `sodium-halide-recent`：钠离子／全固态钠电池卤化物（含氧卤化物、多阴离子卤化物）固态电解质论文。首次在线发表日期在运行当天往前六个月内。优先原创研究；若选择综述，明确标明类型及理由。

交付题名、作者、期刊、首次在线日期、DOI、选文理由、正文与 SI 的下载状态和来源、Zotero 分类／条目／深读笔记链接，以及一两句最有用的研究启发。每次使用新的合格论文，先查本地 Zotero 与既往推荐，按 DOI 去重。

## 选文与下载

1. 从出版方、期刊、Crossref／PubMed 等可靠记录核对题名、DOI、首次在线日期、文章类型。确认期刊属于 Nature／Science 正刊或子刊，或在可核实的当年 JCR Q1／其他用户认可的 SCI 一区顶刊；注明采用哪种分区，不能把不同分区体系混称。优先可合法获取全文与图表的候选。日期不合格或质量无法核实则换候选，不用较旧论文冒充近期文章。
2. 获取出版方开放获取、PMC 官方数据集、机构仓储或作者公开版本的完整 PDF；记录版本及来源。检查文件确实是 PDF、页数可读，且题名／DOI 匹配。访问控制或安全挑战不可绕过；若不能取得完整正文，换候选或如实报告阻碍，不用摘要写“全文深读”。
3. 对选中论文主动检查出版方 Supplementary Information／Supporting Information 链接、论文中的数据／补充材料声明，以及开放存储库的相关附件。凡可获取的 SI 一并下载；逐个确认文件不是错误页、题名／DOI 与正文对应，保留原始格式和来源。若查无 SI，记录核查过的来源；若有 SI 但无法取得，明确列出缺失项与原因。
4. 下载目录沿用本任务工作区的 `固态电池文献/`；正文、SI 用 DOI 或第一作者年份命名，避免覆盖同名文件。保留来源链接与版本信息，勿将自行转换文件称作出版方 PDF。

## Zotero 归档

先阅读可用的 Zotero 技能，使用其状态检查、搜索、分类与导入能力；本地 API 只读，写入使用明确支持的连接器或 Zotero 原生界面。按 DOI 搜索父条目，存在时补齐缺失附件和分类，不新建重复父条目。不存在时导入准确元数据。正文 PDF 与全部 SI 必须作为同一个父条目的子附件，逐一回读核验文件名、类型和父条目。

复用已有的「综述」「卤化物」「硫化物」「聚合物」「氧化物」「正极」等分类；缺少合适分类时才新建。`classic` 默认「综述」，若为经典原创论文则选择其材料／主题分类；`sodium-halide-recent` 默认「卤化物」，相关多类别可同时归入。分类是 Zotero collection，不新建独立 library 或群组库，除非用户明确要求。核验条目确在所选分类。

## 深读与防重复

调用 `$zotero-paper-deep-read` 的完整工作流：阅读正文及已取得的 SI，核对关键图表、方法、条件和证据边界，按四部分十项在父条目下创建中文深度解读子笔记。笔记开头写阅读文件、版本、页数、SI 范围和分析日期；区分作者实测、综述转述和自己的建议。已有同 DOI 的深读笔记时先检查内容与日期；不要因重试创建重复笔记或覆盖用户旧笔记。写入后回读验证 `parentItem`、四部分、第 10 项及结尾，并保存笔记入口。

如果某次没有合格且可读的论文，明确报告搜索范围和阻碍，不杜撰文献、下载或 Zotero 完成状态。定时运行中只在实际完成推荐或需要用户处理阻碍时通知；避免对同一未变化阻碍反复报告。
